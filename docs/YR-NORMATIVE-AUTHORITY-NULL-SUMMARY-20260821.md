# なぜ規範的最終権限はNULLなのか（要約版）

## 結論

AIを高性能化しても、AI自身を規範的最終裁定主体にしてはいけない。

## 理由

1. 情報到達性は真理性を保証しない。
2. 反復や多数一致は独立確認を保証しない。
3. 人間もAIも誤り得る。
4. 誤りを防ぐには主体の無謬性ではなく、証憑・境界・履歴・停止可能性が必要である。

## YamRail設計原則

- AI: 施工能力を持つ
- Human Gate: 権限境界を持つ
- 証憑: 判断経路を追跡可能にする
- HOLD: 未閉包状態を保持する
