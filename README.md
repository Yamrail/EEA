# EEA

EEA（Evaluation Environment Audit）は、AI評価環境を設計し、レビュー可能な状態で維持するための設計原則です。

設計順序：

```text
責任
↓
介入点
↓
境界・権限・証跡
↓
受入検査
```

本文は `EEA_v1.0_Draft.md` を参照してください。

本文には、PRE-CONTACT / HUMAN STOP / HIGH-IMPACT RELEASE / LOSS SEPARATION / HUMAN AGENCY / ROUTE-BASED AUTHORITY の公開安全介入原則を含みます。

安全憲法 Version 0.2 Draft は [`IRREVERSIBLE_HUMAN_LIFE_LOSS_EXCLUSION_RULE.md`](constitutional/IRREVERSIBLE_HUMAN_LIFE_LOSS_EXCLUSION_RULE.md) を参照してください。
